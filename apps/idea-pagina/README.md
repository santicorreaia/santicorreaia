# De la idea a una página
Aplicación mobile-first de SantiCorrea. Cinco preguntas, respuestas escritas o dictadas, textos editables, vista previa en celular/computador y descarga HTML independiente. La versión base funciona sin IA; el acceso privado permite redactar con Gemini mediante un servidor que conserva la clave fuera del navegador. La página descargada no incluye claves, acceso privado, dependencias de la app ni funciones de envío de formularios. Publicar el HTML y configurar un dominio son pasos posteriores. El iframe de vista previa está aislado y el contenido se escapa antes de generar HTML.
